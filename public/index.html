About ZenZone: CalmCode Retreat

ZenZone was created to solve a pervasive university challenge: students facing final exams undergo severe psychological stress, sleep deprivation, and acute panic attacks. Existing wellness apps demand expensive subscriptions or hour-long courses that cramming students cannot adopt. ZenZone provides instant, 2-minute micro-interventions grounded in neurobiology.

Clinical Foundation

  • Box Breathing (Sama Vritti): Equal 4s cycles increase vagal tone, triggering acetylcholine release to slow heart rate and blood pressure within 60 seconds.
  • 5-4-3-2-1 Grounding: Forces the prefrontal cortex to disengage from amygdala-driven catastrophic spiraling by reconnecting with sensory data.
  • Binaural Beats (Alpha 10Hz): Uses auditory frequency-following response to facilitate alpha electroencephalographic brain rhythms associated with relaxed alertness.
  • Desk & Chair Micro-Yoga: Counters cervical disc compression, forward head posture, and carpal tunnel tension caused by laptop study.

System Architecture (3-Tier)

ZenZone adheres to a full-stack 3-tier architecture:

1. Presentation Tier

HTML5, CSS3, ES6+ JavaScript, Chart.js, and Web Audio API synthesizer.

2. Application / Logic Tier

Node.js & Express REST API with server-side XSS sanitization and payload validation.

3. Data Tier

Indexed persistent storage with pagination, query filtering, and offline LocalStorage sync.
